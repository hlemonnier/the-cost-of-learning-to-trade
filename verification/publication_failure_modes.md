# Publication acceptance contract

Recorded before the public-edition code changes on 9 October 2026.

The public edition must fail acceptance if any of the following occurs:

1. The outdated branding or private process metadata survives in a filename,
   tracked text, compressed text, PDF text/metadata, repository description,
   branch, tag or reachable commit message.
2. Packaging leaves imports, module commands, source fingerprints or benchmark
   specification paths referring to the old namespace.
3. Installation in a clean Python environment cannot execute the documented
   smoke reproduction without the author's local caches or environments.
4. Two separate cold subprocess runs disagree on episode records, accounting,
   action admissibility, policy coverage, posterior resets or control hashes.
5. Publication changes numeric source equations, seeds, protocol parameters,
   economic outputs or the negative primary extension conclusion.
6. A report link, Markdown relative link, source reference or PDF build is broken.
7. A retained result is presented as evidence from the renamed source when its
   manifest belongs to the earlier numerical run.
8. A raw data chunk, pilot, action tape, episode ledger, statistical table or
   scientific figure differs from the archived scientific baseline.
9. A reference retains the previous public history after the clean snapshot is
   published, or a concurrent remote change is overwritten.
10. A fresh GitHub clone differs from the accepted local tree or cannot repeat
    the documented end-to-end smoke reproduction.

Retain machine-readable acceptance artifacts, file hashes and exact commands.
The smoke experiment verifies integration and reproducibility; it does not
rerun the expensive full research campaign or establish real-market performance.
