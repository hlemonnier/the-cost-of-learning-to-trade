# Corrective-campaign acceptance contract

Written before implementing the new audit harness or changing report validation.
This records acceptance design, not a replacement for the Linear issues.

The full artifact audit must reject: an incomplete manifest; wrong source/specification
or compressed-data hash; missing, duplicated or relabelled cells; incomplete pilot or
episode budgets; mismatched pairing or fitted-pilot identities; corrupted pilot bytes;
hidden labels in the public pilot; nonfinite economic outcomes; inventory or liquidation
violations; broken cash/objective attribution; inconsistent primary inference; any of
162 inconsistent supplementary contrasts; and economic exports inconsistent with raw
outcomes. It independently calculates pilot-mean Student and uniform-mixture Welch
intervals, without calling the production statistical helpers.

The original reviewed snapshot is audited in an isolated checkout. The corrected
campaign is a corrective replay on the same declared seeds, not fresh independent
confirmation and not an opportunity to select a better-performing convention. Source
and configuration must be frozen before it runs. All 90 public pilot datasets, all
189,000 policy records, 27,000 paired exogenous episodes and 189 cells are required.
The source/build/content provenance for every corrected control table must be saved.

Cold reproducibility requires two separate new cache directories and fresh Python
processes; replaying a shared cache does not satisfy it. The reviewer archive must pass
every recorded file hash. Main PDF/source numbers, eight-page maximum, rendered pages,
Markdown math/figures and repository links must be reviewed after regeneration.

Second-review extension, declared before changing archive validation: a ZIP may be
internally consistent yet stale relative to the current delivered tree. Reject an
archive whose member list, embedded inventory, external status hash/size or any
member's current-tree bytes differ. A self-consistent old ZIP is historical
evidence, not a current delivery receipt.
